# Lightweight Linux Distribution

Собственный source-based Linux-дистрибутив для x86_64, собираемый на базе
Linux From Scratch (LFS). Проект ориентирован на производительность,
отзывчивость, низкое потребление ресурсов и совместимость со старыми и
современными ноутбуками.

> **Текущий статус:** Phase 0 и Phase 1 — документация и инфраструктурный
> фундамент подготовлены; Phase 2 — **AUTHORIZED, ожидается развёртывание
> постоянной Build VM**. Загружаемого ISO и готовой ОС пока нет.
> Актуальный источник статуса — [`PROJECT_STATUS.md`](PROJECT_STATUS.md).

## Цели проекта

- Быстрая и отзывчивая система на старом x86_64-оборудовании.
- Контролируемое потребление RAM, CPU и дискового ввода-вывода.
- Широкая поддержка оборудования: графика, Wi-Fi, звук, Bluetooth,
  ACPI, аккумулятор и тачпад.
- Воспроизводимая сборка из исходников.
- Собственная поддерживаемая ветка конфигурации и патчей Linux Kernel.
- Удобная графическая среда и понятное обслуживание системы.

## Текущая техническая база

- Архитектура: x86_64.
- Bootstrap: LFS 13.1-systemd.
- Планируемая ветка ядра: Linux 6.18.y LTS.
- Init: systemd.
- Libc: glibc.
- Bootloader: GRUB.
- Файловая система первой базовой конфигурации: ext4.
- Планируемая графическая среда: Xfce.

Архитектура обновлений и отката остаётся открытым решением: см. ADR-0008.

## Проверки проекта

Из корня репозитория:

```bash
make help
make self-test
make adr-lint
make shellcheck
make check
```

`make check` включает host-version-check. Отсутствие build-зависимостей на
обычной рабочей машине может быть ожидаемым результатом; целевой build host
проверяется отдельно по `docs/BUILD_ENV_SETUP.md`.

## Важные ограничения безопасности

- Не запускайте команды разметки или форматирования дисков без проверки
  `lsblk` и однозначной идентификации целевого **виртуального** диска.
- Не устанавливайте загрузчик на физический диск основного компьютера.
- Сборка LFS выполняется от отдельного непривилегированного пользователя
  `lfs`, без `sudo`.
- Не отключайте Hyper-V, VBS, Memory Integrity, Defender или другие функции
  безопасности Windows ради Nested KVM. QEMU TCG допустим для функциональной
  проверки загрузки, но не для достоверных performance benchmarks.
- A/B-обновления не утверждены и не реализуются до отдельного решения по
  ADR-0008.
- Не выполняйте `git push` или публикацию релизов без отдельной проверки.
